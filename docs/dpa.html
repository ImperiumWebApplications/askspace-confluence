Data Processing Addendum (DPA)

Effective Date: November 24, 2026 · Vendor: AskSpace Software · Product: AskSpace - Questions & FAQ for Confluence

1. Roles & Scope

This Data Processing Addendum ("DPA") forms part of the End-User License Agreement between Customer ("Data Controller") and AskSpace Software ("Data Processor") solely to the extent AskSpace processes Personal Data within Atlassian Cloud in connection with Customer's use of AskSpace - Questions & FAQ for Confluence.

2. Categories of Data Processed

  • Data Subjects: Authorized Confluence Cloud users of the Customer's Atlassian site.
  • Personal Data: Atlassian Account ID, public display name, and user-authored Q&A content (questions, answers, comments, votes, watch subscriptions, and governance audit logs).
  • Special Categories: AskSpace is not intended for storing special-category sensitive data, financial account numbers, or protected health records.

3. Zero External Storage & Subprocessors ("Runs on Atlassian")

AskSpace executes 100% natively on Atlassian Forge compute and stores all tenant data exclusively inside Atlassian-hosted, tenant-isolated Forge SQL storage. AskSpace Software operates no external servers, performs zero outbound End-User Data egress, and engages zero third-party data subprocessors beyond Atlassian's native Forge platform infrastructure covered by Customer's existing Atlassian Cloud DPA.

4. Data Residency, Security & Erasure

  • Data Residency: All Forge SQL data automatically inherits the Data Residency region pinned on Customer's Confluence Cloud site.
  • Access Controls: All Confluence REST operations execute via api.asUser() adhering to the signed-in user's Confluence permissions.
  • Deletion & DSR Support: Customer users and administrators may delete questions and answers at any time in-app (cascading to all linked records), and uninstalling the app removes tenant storage per Atlassian Forge lifecycle policies.
  • Breach Notification: AskSpace Software will notify Customer without undue delay (and within 72 hours) upon becoming aware of any verified security incident affecting Customer Personal Data.

5. Contact

For DPA execution requests or data protection inquiries, email support@askspace.app.
